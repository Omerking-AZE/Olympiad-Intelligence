# Data

This directory contains the datasets and processed data used by **Olympiad Intelligence**.

## Dataset Source

The main dataset used by the project is **MathNet**.

MathNet contains approximately **27,817 mathematical olympiad problems** from different countries and competitions.

For the current development stage, the project uses a **1,000-problem working sample**.

## Main Dataset

`mathnet_problems.csv`

This is the standardized dataset used by the current research pipeline.

It contains information such as:

- Problem ID
- Problem statement
- Country
- Competition
- Mathematical domain
- Subtopic
- Mathematical concepts
- Problem type
- Language
- Final answer when available
- Proof requirement

## Processed Files

### `features.csv`

Initial feature-engineering dataset created during the early development stage.

### `mathnet_features.csv`

Contains structural features extracted from the MathNet problems.

### `mathnet_model_features.csv`

Contains features prepared for machine-learning experiments.

### `mathnet_difficulty.csv`

Contains the output of the current difficulty engine.

Important fields include:

- `difficulty_score`
- `difficulty`
- `difficulty_label`
- `length_score`
- `equation_score`
- `reasoning_score`
- `proof_score`
- `case_score`
- `steps_score`
- `problem_type_score`
- `domain_score`

Current difficulty labels:

- Easy
- Medium
- Hard
- Very Hard

These are research labels generated by Olympiad Intelligence and are **not official olympiad difficulty ratings**.

### `solution_feature_report.txt`

Contains statistical analysis of the extracted solution features, including distributions, missing values, variance, correlations, and feature relationships.

## Solution Features

The current pipeline extracts features such as:

- Solution length
- Solution word count
- Number of paragraphs
- Equation count
- Reasoning indicators
- Proof indicators
- Case analysis
- Calculation indicators
- Major solution steps
- Equation density
- Reasoning density
- Proof density

## Solution Coverage

In the current 1,000-problem sample:

- **884** problems have solutions
- **116** problems do not have solutions
- Solution availability: **88.4%**
