# Data — Olympiad Intelligence

This directory contains all data used by the Olympiad Intelligence research pipeline. It is organized into a `raw/` layer (untouched source data) and a `processed/` layer (outputs produced by the scripts in [`src/`](../src)).

```
data/
├── raw/          # Original, unmodified source data
├── processed/    # Converted / feature-engineered / difficulty-scored data
└── README.md     # This file
```

> **Note:** Large raw and processed files are typically not committed to version control (see `.gitignore`). This document describes the *shape* of the data — check `.gitignore` / your local setup for what is actually tracked in Git.

---

## Source Dataset — MathNet

The project's data originates from **MathNet**, a dataset of **27,817 mathematical olympiad problems** collected from countries and competitions around the world.

For the current development stage, the project works with a **1,000-problem sample** drawn from the full MathNet dataset.

### Fields available per problem

| Field | Type | Description |
|---|---|---|
| `problem_statement` | text | Full text of the olympiad problem |
| `solution` | text | Reference solution, when available |
| `country` | categorical | Country of origin of the competition |
| `competition` | categorical | Name of the competition/olympiad |
| `topic` | categorical | Fine-grained mathematical topic |
| `domain` | categorical | Broader mathematical domain (see below) |
| `problem_type` | categorical | Proof and answer / Proof only / Final answer only / MCQ |
| `language` | categorical | Original language of the problem |
| `final_answer` | text/numeric | Final answer, when available |
| `requires_proof` | boolean | Whether a formal proof is required |

**Mathematical domains** currently present in the working sample: Geometry, Algebra, Discrete Mathematics, Number Theory, Statistics, Precalculus, Calculus, Math Word Problems. Some problems belong to multiple domains.

## `raw/`

Contains the MathNet data as originally obtained, before any project-specific transformation. Nothing in this folder should be edited by hand — it exists purely as the input to `src/inspect_mathnet.py` and `src/convert_mathnet.py`.

If you are setting this repository up locally, place the original MathNet export(s) here before running the pipeline.

## `processed/`

Contains the outputs generated by running the scripts in [`src/`](../src) in order. Depending on which stages you have run, this typically includes:

| Stage | Produced by | Typical content |
|---|---|---|
| 1. Conversion | `convert_mathnet.py` | The 1,000-problem working sample in a clean, tabular format |
| 2. Problem feature engineering | `feature_engineering.py` | Problem-level features (domain, type, language, etc. encoded for modeling) |
| 3. Solution feature extraction | `extract_solution_features.py` | Structural solution features — see table below |
| 4. Solution feature analysis | `analyze_solution_features.py` | Aggregated statistics / analysis outputs over the extracted features |
| 5. Difficulty engine | difficulty scoring step | `difficulty_score`, `difficulty`, `difficulty_label` per problem |

> Exact output filenames depend on your local pipeline configuration — check the corresponding script in `src/` for the precise path it writes to, and update this table to match once finalized.

### Solution features (from `extract_solution_features.py`)

- `solution_length`
- `solution_words`
- `solution_paragraphs`
- `equation_count`
- `reasoning_indicators`
- `proof_indicators`
- `case_analysis`

- `solution_major_steps`
- `equation_density`
- `reasoning_density`
- `proof_density`
- `log_solution_length`
- `log_equation_count`

**Solution coverage in the current 1,000-problem sample:**

| Metric | Value |
|---|---|
| Problems with available solutions | 884 |
| Problems without available solutions | 116 |
| Solution availability | 88.4% |

### Difficulty labels (from the difficulty engine)

| Label | Description |
|---|---|
| Easy | Lower estimated structural complexity |
| Medium | Moderate estimated structural complexity |
| Hard | Higher estimated structural complexity |
| Very Hard | Very high estimated structural complexity |

These labels reflect the project's current research methodology and are **not official olympiad difficulty ratings**.

## Regenerating the processed data

From the repository root, with `raw/` populated:

```bash
python src/inspect_mathnet.py
python src/convert_mathnet.py
python src/feature_engineering.py
python src/extract_solution_features.py
python src/analyze_solution_features.py
```

Each step reads from `data/raw/` or the output of the previous step, and writes its results into `data/processed/`.
