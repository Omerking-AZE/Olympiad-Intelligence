# Data Schema

## Problem Table

Each row represents one mathematical problem.

### Identification

- problem_id
- source
- competition
- year
- country

### Mathematical Metadata

- domain
- subtopic
- concepts
- prerequisites

### Structural Features

- solution_depth
- estimated_time_minutes
- proof_required
- reasoning_intensity
- calculation_intensity
- major_steps

### Difficulty

- difficulty
- difficulty_source

### Student Performance

Future versions may include:

- student_success_rate
- median_solving_time
- attempts
- hint_count
- error_rate

Student identifiers will be anonymized.
