# Mathematical Problem Taxonomy

## Purpose

This taxonomy defines the mathematical domains and subtopics used by the Olympiad Intelligence dataset.

The taxonomy is designed to support:

- mathematical problem classification
- difficulty analysis
- student skill modeling
- adaptive problem recommendation
- machine learning experiments

---

- Complex Numbers
- Algebraic Manipulation

# Problem-Level Features

Each problem may additionally contain:

- Difficulty
- Required Concepts
- Prerequisites
- Solution Depth
- Estimated Solving Time
- Proof Requirement
- Reasoning Intensity
- Calculation Intensity
- Number of Major Steps

---

# Difficulty

The initial dataset uses a provisional difficulty score from 1 to 10.

This score is NOT considered ground truth.

Future versions will investigate empirical difficulty using:

- student success rate
- solving time
- number of hints required
- number of attempts
- reasoning errors
